# Submission pack overview

Assemble seven components under `# <Venture name>`, retaining the headings below. Phase A develops the venture; Phase B introduces stakeholder challenges; Phase C revises and defends the recommendation. December participation is voluntary and separate from module assessment.

| Component heading | Phase | Content and word limit |
|---|---|---|
| `## 1. Venture Brief` | A; revise in C | Problem, target customer, solution, business model, key assumptions table. Maximum 400 words. |
| `## 2. AI-Use Declaration: Stage 1` | A | Tools, purposes, what AI produced, verification and method, changes or rejections. Maximum 200 words. |
| `## 3. Stakeholder Response Log` | B; update in C | One short paragraph per role, followed by decisions, reasons, and evidence that would change them. No numerical word limit specified. |
| `## 4. Decision Memo` | C | Opportunity, evidence, feasibility judgement, stakeholder conflict and resolution, ethical trade-off, recommendation, uncertainty. Maximum 500 words; one page. |
| `## 5. Venture Value Map` | First in A; revise in C | Industry, material topics, anticipated harms and response, alignment thesis. Thesis maximum 120 words; no overall map word limit specified. |
| `## 6. AI-Use Declaration: Final` | C | Updated AI use, verification and revisions, where human judgement is most visible, responsibility statement. Maximum 150 words. |
| `## 7. Oral Defence Excerpt` | C, after defence | Five actual judge questions, one per cluster, with team answers. No numerical word limit specified. Live defence: 8 to 12 minutes. |

Use the supplied templates, including their exact subheadings. The venture brief's assumptions table uses `assumption | tested/untested | how to test`. The map templates are in `04_venture_value_lens/`.

Keep Phase A and revised versions distinguishable. Remove prompts before submission. Working counting convention: include submitted prose and table entries within each capped component; exclude fixed headings and empty prompts. No extra appendix is required.

Cite evidence briefly and distinguish observations, assumptions, and simulated feedback. Each stakeholder decision uses ADOPT, PARTIALLY ADOPT, REJECT, or DEFER with reasons and evidence that would change it. Identify any paraphrase in the defence excerpt; never present prepared answers as a live record. The presentation accompanies Phase C and does not add an eighth component.

Designed for a one-page handout; final pagination depends on export settings.
