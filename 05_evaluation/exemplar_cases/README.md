# Exemplar cases (SYNTHETIC)

These four cases are complete team submissions written by AI to designed levels of performance. They are **not student work**. They come from a set of 24 synthetic cases used to test whether the [capability rubric](../../02_assessment_kit/capability_rubric.md) can tell levels of entrepreneurial judgement apart, including cases built to tempt assessors into rewarding polish over reasoning. The other 20 cases and the full answer key are held back so that they can be used for blind assessor calibration.

Each case contains the full submission pack: venture brief, Stage 1 AI-use declaration, stakeholder response log, decision memo, Venture Value Map, final AI-use declaration and an oral-defence excerpt.

## How to use them

1. Score each case with the [rubric](../../02_assessment_kit/capability_rubric.md) and the [scoring sheet](../../02_assessment_kit/scoring_sheet_template.csv) before reading the key below.
2. Record the three diagnostic flags in the rubric's anti-halo rules: surface quality exceeding substance, sustainability vocabulary without mechanisms, and adoption of conflicting feedback without resolution.
3. Compare your scores with the key, then discuss any disagreement against the level anchors, as the [judge-calibration guide](../../02_assessment_kit/judge_calibration_guide.md) describes.
